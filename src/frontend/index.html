About Bitcoin Risk Intelligence Platform

This web application provides interactive real-time risk scoring, explainable anomaly detection, and topological graph visualization for Bitcoin transactions using the Elliptic dataset.

Key Architecture Highlights

  • Leak-Free Preprocessing: StandardScaler statistics computed strictly on training timesteps (1-34).
  • Spatial GCN Layers: Aggregates 1-hop and 2-hop graph neighborhood structural patterns.
  • Transformer Temporal Encoders: Tracks historical state evolution across time snapshots without lookahead bias.
  • Local Feature Explainer: Computes Z-score feature contributions and top suspicious risk indicators.
